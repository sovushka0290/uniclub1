## ✨ О проекте
Проект демонстрирует, как связка человеческого видения и искусственного интеллекта может создавать премиальные образовательные интерфейсы. Мы объединили классическое музыкальное образование с технологиями будущего.

### 🌟 Ключевые особенности
- **High-End Minimalist Design:** Интерфейс в стиле Apple/Linear, сфокусированный на чистоте и контенте.
- **Interactive Piano Prototype:** Виртуальный инструмент прямо в браузере для моментальной практики.
- **Student & Director Dashboards:** Готовые макеты для управления обучением и школой.
- **Vite-Powered Performance:** Мгновенная загрузка и плавная работа интерфейса.

## 🛠 Технологический стек
- **Runtime:** Vite + Vanilla Javascript
- **Styling:** CSS3 (Modern Minimalist Design System)
- **Icons:** Lucide Icons
- **AI Architect:** Google AI Studio (Gemini 2.0 Flash)

## 🚀 Как запустить
Благодаря **Google AI Studio**, переход от идеи к рабочему коду занимает секунды. Чтобы запустить проект локально:

```bash
# Клонировать репозиторий
git clone https://github.com/sovushka0290/uniclub1.git

# Установить зависимости
npm install

# Запустить сервер разработки
npm run dev
```
